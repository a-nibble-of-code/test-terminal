PROJECT: PALE SIGNAL — Terminal Beta

WHAT'S INCLUDED
- index.html: a self-contained, responsive, retro archive terminal.
- Commands: HELP, SEARCH, RECORD, PERSONNEL, ACCESS, LOG, CLEAR, STATUS, WHOAMI, EXIT.
- Fictional records and several early clues for the ARG.

RUN LOCALLY
1. Extract the ZIP.
2. Open index.html in Chrome, Firefox, or Edge.
3. Type HELP, then try SEARCH 0017, RECORD 0041, PERSONNEL VENN, and ACCESS SECOND_ARCHIVE.

PUBLISH ON FREE GITHUB PAGES
1. Sign in to GitHub and create a new PUBLIC repository (for example: pale-signal-terminal).
2. Upload index.html to the repository root.
3. Open Settings -> Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Choose the main branch and /(root), then Save.
6. Wait for the published Pages URL to appear.

NOTES
- This is a beta mockup, not a secure login system. Passwords or secret content in client-side code are not private.
- It collects no visitor data and uses no paid services.
- Check your account's age, school, and platform restrictions before publishing.
